# 8BitDo Retro Numpad Calculator

A retro handheld numpad-inspired calculator modeled after the **8BitDo Retro 18 Mechanical Numpad** translucent green edition.

## Project Structure
- `index.html` — Semantic handheld layout with rotary mode dial, 3 top function buttons, recessed 7-segment LCD screen, and 4-column mechanical keycap grid.
- `styles.css` — Translucent olive/forest green shell styling, sculpted dished keycaps with yellow legends, 2u `0` and vertical `ENTER` keys, and responsive layout rules.
- `script.js` — Order-of-operations (PEMDAS) expression evaluator, keyboard support, sign toggle (`+/−`), percentage (`CAL%`), power/mode dial (`BT / OFF / 2.4`), and Web Audio tactile key clicks.
